Chrome's approval rule

Chrome does not allow a normal installer to silently add an unpacked extension for consumers. That is good for safety. The closest non-technical path is this setup helper plus one visible Chrome approval step.

For true one-click public distribution, publish the extension in the Chrome Web Store. For company-managed machines, use Chrome enterprise policy deployment.
